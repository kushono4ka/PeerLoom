**[ НАЗВАНИЕ ПРОЕКТА ]**

“PeerLoom – платформа для обмена навыками”

**[ ПРОБЛЕМНОЕ ПОЛЕ ]**

Ученики Лицея обладают разнообразными навыками, но не имеют удобной площадки для обмена ими. Объём знаний, которым школьники могут поделиться друг с другом, постоянно растет, однако существующие способы коммуникации (общие чаты, сарафанное радио, поиск в интернете) неэффективны. В них **отсутствует**: 1) структурированный поиск по конкретным навыкам и областям знаний, 2) система рейтинга и отзывов, подтверждающая компетенцию наставника, 3) возможность сохранить понравившуюся анкету («Избранное») на будущее. По результатам опроса 80 лицеистов, 58% обладают навыком, которым можно поделиться, более 70% хотели бы научиться чему-то новому у других лицеистов, а около 85% сталкивались с проблемой поиска человека для помощи. Заявляемый продукт позволит решить эти проблемы, создав безопасную локальную среду для обмена знаниями. 

**Ключевые показатели эффективности (KPI):**
* Снижение времени поиска наставника (с дней до 10 минут).
* Вовлеченность (не менее 15 регистраций и 5 успешных обменов к защите).
* Уровень доверия (средний рейтинг наставников не ниже 4 из 5).

**[ ЗАКАЗЧИК / ПОТЕНЦИАЛЬНАЯ АУДИТОРИЯ ]**

Продукт рассчитан на учеников Лицея НИУ ВШЭ. Можно выделить две основные группы пользователей:

* **Лицеисты-наставники (9–11 классы):** обладают навыками и готовы обучать им других, заинтересованы в получении рейтинга и обратной связи.
* **Лицеисты-ученики (8–11 классы):** которым требуется помощь в освоении нового навыка, подготовке к контрольным или проектам.

**[ АППАРАТНЫЕ / ПРОГРАММНЫЕ ТРЕБОВАНИЯ ]** 

Продукт разрабатывается в виде веб-приложения. Для полноценной работы не требуется установка дополнительного ПО.

* **Устройства:** любые ПК, ноутбуки, планшеты и смартфоны.
* **Облачная версия:** современные браузеры (Chrome, Safari, Firefox, Edge) с доступом в интернет.

**[ ФУНКЦИОНАЛЬНЫЕ ТРЕБОВАНИЯ ]**

Программный продукт будет предоставлять следующие возможности:

1. **Управление аккаунтом:** регистрация, вход/выход, редактирование профиля.
2. **Управление навыками:** добавление, редактирование и удаление навыков в категориях «Могу научить» и «Хочу научиться».
3. **Категоризация:** распределение навыков по областям знаний (например, «Математика», «Программирование»).
4. **Поиск:** нахождение анкет по названию конкретного навыка.
5. **Фильтрация и сортировка:** отбор анкет по областям, классам или рейтингу.
6. **Работа с «Избранным»:** сохранение анкет для быстрого доступа.
7. **Система заявок:** отправка предложения об обмене, принятие/отклонение входящих заявок.
8. **Внутренний чат:** обмен сообщениями внутри заявки.
9. **Система рейтинга:** выставление оценки (1–5 звезд) и написание отзывов после обмена.
10. **Просмотр статистики:** средний рейтинг и история отзывов в чужом профиле.

**[ ПОХОЖИЕ / АНАЛОГИЧНЫЕ ПРОДУКТЫ ]**

Анализ 2 программных продуктов, которые максимально приближены к заданному функционалу, показал, что:

* **SkillSwap:** ориентирован на глобальный рынок и взрослую аудиторию. Отсутствует привязка к локальному учебному заведению, что делает невозможным поиск партнера для офлайн-встреч в рамках школы.
* **TalentTrade:** использует систему кредитов (credits), где ценность навыка зависит от сложности, что создаёт неравные условия для новичков. Приложение ориентировано на iOS, что ограничивает аудиторию.

**[ ИНСТРУМЕНТЫ РАЗРАБОТКИ, ИНФОРМАЦИЯ О БД ]**

* **Серверная часть:** Python 3 / Django / Django REST Framework.
* **Клиентская часть:** TypeScript / React.
* **База данных:** PostgreSQL (через Django ORM).
* **Инфраструктура:** Docker, GitHub Actions (CI/CD).
* **Контроль версий:** Git, GitHub.
